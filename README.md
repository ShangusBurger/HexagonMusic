# Hexagon Music

A music-making game prototype built in Unity, developed as part of a master's thesis in Game Technology at Breda University of Applied Sciences.

Hexagon Music is a step sequencer laid out on a hexagonal grid. Players send signals around the map via towers, each with different functionality for manipulating signal direction and timing. The result is a spatial music composition tool where rhythmic patterns emerge from the arrangement of towers on the grid.

Three iterations of the prototype were developed as part of a Research through Design methodology, each implementing a different progression system to explore how reward contingency affects player motivation and creative autonomy.

## Repository Contents

This repository contains the full Unity project files, including all scripts, assets, scenes, and configurations across the three design cycles.
